# Dragon Ball Horizons

Public start-here website and playtest downloads for the Minecraft Java fan modpack.

Visit https://jakailindquist-png.github.io/dragon-ball-horizons/

Version 0.1.1. Requires Minecraft Java 1.20.1, Forge 47.4.0 and Java 17. Import the .mrpack with Prism Launcher.
