# Dragon Ball Horizons

Public start-here website and playtest downloads for the Minecraft Java fan modpack.

Visit https://jakailindquist-png.github.io/dragon-ball-horizons/

Stable pack: version 0.1.2. Requires Minecraft Java 1.20.1, Forge 47.4.0 and Java 17. Import the .mrpack with Prism Launcher.

Experimental Demon Realm preview: version 0.2.0-alpha.5. It repairs older Otherworld Yemma and Baba placements, adds `/dmznpc sethere` for world-specific placement recovery, and rebuilds Janemba's procedural arena after reset. Alpha.4's fixed structure NPC and native quest reset repairs remain included. Download from https://jakailindquist-png.github.io/dragon-ball-horizons/demon-realm-preview.html or https://github.com/jakailindquist-png/dragon-ball-horizons/releases/tag/v0.2.0-alpha.5. Back up your world and import the pack as a new Prism instance; every LAN player needs the same pack.

Unofficial fan project. See THIRD-PARTY.html for credits and VALIDATION.html for tested behavior and limitations.
