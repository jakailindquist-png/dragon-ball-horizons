Explore the Demon Realm

This separate preview combines Horizons with a locally modified build of DragonMine Z’s public GPL-3.0 2.2-alpha source. It adds the three Demon Worlds, the Daima saga, Tamagami 1–3, Gomah, and new Janemba, Turles and Metal Cooler Core world bosses. The stable 0.1.2 pack remains available on the main download page.

Keep your current world safe

  1. Close Minecraft and make a full backup of your current world.
  2. In Prism Launcher, choose Add Instance → Import and select this .mrpack. Use Java 17.
  3. Copy your backed-up world into the new instance’s saves folder. Keep your original instance and save untouched.
  4. Launch the new instance. DragonMine Z may update native quest data when it first loads the copied world. Do not reopen that upgraded copy with 0.1.2.

Play with friends

All players import the same local/LAN pack. The host opens their world with Esc → Open to LAN; friends join using the address shown in chat. A separate dedicated server still requires upstream beta access. Live two-player LAN play has not yet been verified.

The native Space Pod unlocks the Demon Realm after Daima Saga quest 3. Time Patrollers sell maps to Tamagami lairs. Operators can use /dmzworldboss locate for world-boss directions.

What has been verified: the alpha and Horizons compiled; the original fresh-world server passed 17 integration tests, including Demon Realm and seven boss registrations; the local/LAN build passed compilation and archive checks. Full Windows graphics, boss fights, existing-save migration and live LAN play have not yet been tested. This is an unofficial modified preview, not an official DragonMine Z release.
